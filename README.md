# 红脉岭南 · 广东红色场馆数字地图

> 课程主题：数绘湾区红脉 · 践行医者初心

> 2026 年秋季学期《形势与政策》课程实践教学活动 · 思政数字地图创作大赛作品

一个可交互的**网址数字版思政地图**：进入即是地球，自动放大到中国版图；
点选任一省份即整幅高亮，随后其下辖市 / 州**按「省会先行 → GDP 由高到低」逐个渐出**；
继续下钻可至区县，接入高德行政区划服务后还可展开街道 / 镇 / 乡。

**在线访问**：<https://wangji330330-ops.github.io/116/>

## 一、核心交互

| 层级 | 展开规则 | 数据来源 |
| --- | --- | --- |
| 中国（34 个省级行政区） | 按 GDP 由高到低排列 | DataV 行政区划 + 2023 年省级 GDP |
| 省 → 市 / 州 | **省会 / 首府先行**，其余按 GDP 降序渐次淡入 | DataV + 2023 年地级市 GDP |
| 市 → 区县 | 已收录 GDP 的按降序，其余按行政区划代码 | DataV + 部分区县 GDP |
| 区县 → 乡镇 | 街道 / 镇 / 乡（需配置高德 Key） | 高德开放平台行政区查询 |

具体动效：

1. **地球开场** —— 卫星影像地球自动飞入中国疆域；落地后立即切为平面投影（球面渲染开销约为平面的 2 倍，只保留在开场镜头）并切换为国家标准公开版地图；
2. **先全国后广东** —— 34 个省级行政区依次弹出后，自动飞入**广东省**（本作品只做广东）；
   其他省份只作版图参照，点击会提示「仅收录广东省」，不予进入；
3. **滚轮跟随鼠标** —— 滚轮缩放以光标为锚点，滚到哪放大到哪，不用再回头点进度条；缩放速率已调快；
4. **点区块即进入** —— 命中判定不依赖渲染拾取，而是**直接对已加载的 GeoJSON 做点面几何判定**，
   因此无论填充多淡、渲染状态如何，点市 / 区县的**区域**都一定进得去；
5. **点省即聚焦** —— 进入广东后，该省几何中心落到屏幕正中，全省高亮加深；
6. **省会领跑 → 依次渐出** —— 省内市 / 州按「省会先行，其余依次」逐个弹出；
7. **跨级可点** —— 任意层级都能直接点到别处：上一层标记降级为浅色小点、同市区县保持可点、
   本省其他市以虚线轮廓常驻；层级归属沿 parent 链自动校正；
8. **红色传承自动浮现** —— **当某个市 / 区县在屏幕上占据 ≥75% 的面积时**，
   左下角自动浮出该地的「红色传承」卡片（列出收录的红色场馆），
   同时在图上以红色填充该地块——**填充严格裁剪在该地块边界内，不会溢出到相邻市区**；
9. **红色资源检索** —— 右上角 **⌕** 展开搜索框，输入场馆名、地址或地名即可直达；
10. **说明面板分层名录** —— 64 处场馆按 **省 › 市 › 区县 › 乡镇** 四级树展开，可折叠、可搜索；
11. **广东立体浮雕** —— 右上角「3D」把广东省 21 个地市拉成**轻微起伏的浮雕**
    （高度 = 该市红色场馆数量，最高约省域宽度的 3%），既看出差异又不遮挡底图；
12. **悬停看所属** —— 鼠标划过任意区块，即时浮出名称与完整层级；
13. **沉浸看图** —— 右上角「隐」或快捷键 **H**，隐藏后右上角留「显」按钮找回；
14. **南海诸岛附图** —— 右下角常驻十段线附图，国家版图完整。

### 界面控件

`⌕` 搜索 · `隐` 隐藏界面 · `3D` 立体浮雕 · `↻` 重播开场 · `卫` 卫星/标准底图 · `说` 作品说明 · `全` 全屏

### 收录范围

本作品**仅收录广东省**的红色场馆与红色文化资源（依据课程附件《广东革命文化与红色记忆场馆名录》，共 64 处）。
**未收录其他省、自治区、直辖市的红色点位**——点开其他省份时仅显示行政区划，不含场馆数据。

### 加载速度

区县「点进去要等很久」的问题已从三方面解决：

| 手段 | 效果 |
| --- | --- |
| 悬停即预取下一级边界 | 鼠标扫过时数据已进内存，点击基本秒开 |
| 上级展开完成后后台预取 | 空闲时按 3 个一批预热所辖市，不抢当前带宽 |
| 数据加载与镜头动画并行 | 不再「先飞完再加载」，两者同时进行 |

实测：点击广州市到第一个区县出现 **约 2 秒 → 282 ms**。

### 性能取舍

卡顿主要来自三处，已逐一处理：

| 问题 | 处理 |
| --- | --- |
| 球面投影渲染开销大（实测约为平面的 2 倍） | 仅开场使用球面，落地即切平面 |
| `mix-blend-mode` 全屏叠层 + `backdrop-filter` 毛玻璃 | 全部移除，改为纯色半透明面板 |
| 瓦片淡入混合、标签逐帧强制回流 | 关闭瓦片淡入；标签改为「先批量读尺寸、再批量写位置」并缓存 |

### 两极显示

球面/平面投影在极点附近都会出现瓦片拉花。落地中国后把可平移范围限制在
`[[40,-12],[165,70]]`（含港澳台与南海，但够不到极点），并把中心纬度钳制在 ±72°，
极点无法再被拖到屏幕中央。

实测同一视角平移帧耗时：**101.7 ms → 47.6 ms**（约 2.1× 提速）。

## 三、本地运行（双击即可，无需任何环境）

**直接双击 `index.html` 就能打开**，不需要安装 Node、Python，也不需要启动服务器。

实现方式：行政区划与场馆数据以 `.js` 形式按需注入（`window.__GEO_SET`），
绕开浏览器对 `file://` 下读取本地 JSON 的限制；地图引擎 MapLibre 本身在 `file://` 下可正常工作。

> 若你更习惯用本地服务器，也可以执行 `node tools/serve.mjs`（默认 <http://127.0.0.1:8123/>）。

│   ├── geo/                 行政区划边界（.js 形式，省 / 市两级全部本地打包）

│   ├── red-sites.geo.js     红色场馆经纬度（地理编码结果，GCJ-02）
│   └── red-sites.resolved.js 场馆所属区县 / 乡镇归属
├── vendor/                  MapLibre GL JS v5.6.0
└── tools/
    ├── serve.mjs            本地静态服务器（可选）
    ├── build-jsdata.mjs     JSON → .js 数据转换（改完数据后运行）
    ├── fetch-geo.mjs        重新下载省级行政区划边界
    ├── fetch-geo-districts.mjs  重新下载地级市行政区划边界

> 所有行政区划边界均已离线打包（约 26 MB），因此站点**不依赖任何第三方数据接口**，
> 只在加载底图瓦片时联网。首次打开与逐级下钻都很快，且不会因外部服务限流而失效。

## 五、红色场馆精确点位

`data/red-sites.geo.json` 存放 64 处场馆的**真实经纬度**，由高德地理编码生成：

```bash
node tools/geocode-red-sites.mjs <高德Web服务Key>
```

- 坐标系为 **GCJ-02**，与高德底图完全一致，无偏移；
- 生成后，进入市 / 区县时该地场馆会以金色点位落在**实际街道地址**上，点击可看名称与详细地址；
- 没有坐标的场馆不会出点（不留假点位）。

> Key 申请免费：<https://lbs.amap.com/> → 控制台 → 应用管理 → 创建应用 → 添加 Key，
> **服务平台必须选「Web 服务」**。Key 只用于本地生成，脚本从命令行参数读取，不写入仓库。

## 六、接入乡镇级（可选，且免费）

**省 → 市 → 区县 三级开箱即用，不需要任何 Key、不需要付费。**

点击区县时，右侧会打开该区县的资料页（所属市、GDP、本层名次、所在市红色场馆名录），
作品内容完整可看。

若希望继续展开到**街道 / 镇 / 乡**并绘制其边界，才需要调用高德行政区划接口：

1. 前往 <https://lbs.amap.com/> 注册开发者（个人开发者有**免费调用额度**，无需付费）；
2. 控制台创建应用，添加 Key，服务平台选择 **Web 服务**；
3. 把 Key 填入 `config.js` 的 `AMAP_KEY`。

填入后，区县点击会自动请求高德行政区查询接口，解析 `polyline` 边界并绘制乡镇图层；
不填则保持现状，不影响任何其他功能。

## 六、数据更新

`data/gdp.js` 中的数值为 **2023 年公开统计口径整理值**，仅用于排序演示。
正式报送前请以《中国统计年鉴》《广东统计年鉴》核准，修改后运行：

```bash
node tools/validate-data.mjs
```

该脚本会校验每个键名是否与行政区划边界数据完全匹配，避免因名称不一致导致排序失效。

- 原生 JavaScript / CSS，无构建步骤
