# 数绘湾区红脉 · 践行医者初心 —— 思政数字地图

> 2026 年秋季学期《形势与政策》课程实践教学活动 · 思政数字地图创作大赛作品

一个可交互的**网址数字版思政地图**：进入即是地球，自动放大到中国版图；
点选任一省份即整幅高亮，随后其下辖市 / 州**按「省会先行 → GDP 由高到低」逐个渐出**；
继续下钻可至区县，接入高德行政区划服务后还可展开街道 / 镇 / 乡。

**在线访问**：<https://wangji330330-ops.github.io/116/>

---

## 一、核心交互

| 层级 | 展开规则 | 数据来源 |
| --- | --- | --- |
| 中国（34 个省级行政区） | 按 GDP 由高到低排列 | DataV 行政区划 + 2023 年省级 GDP |
| 省 → 市 / 州 | **省会 / 首府先行**，其余按 GDP 降序渐次淡入 | DataV + 2023 年地级市 GDP |
| 市 → 区县 | 已收录 GDP 的按降序，其余按行政区划代码 | DataV + 部分区县 GDP |
| 区县 → 乡镇 | 街道 / 镇 / 乡（需配置高德 Key） | 高德开放平台行政区查询 |

具体动效：

1. **地球开场** —— 卫星影像地球自动飞入中国疆域；落地后立即切为平面投影（球面渲染开销约为平面的 2 倍，只保留在开场镜头）并切换为国家标准公开版地图；
2. **点省即聚焦** —— 点选省份后，**该省几何中心落到屏幕正中**，全省高亮加深、边界描红加粗，
   其余省份统一淡化（浅灰填充 + 细灰边界），省名标签同步变淡；
3. **省会领跑 → GDP 渐出** —— 省内市 / 州依次浮现，配脉冲光环、缩放淡入与名次标签，
   左下角进度条实时显示「正在展开 3 / 21 · 佛山市」；
4. **标签避让** —— 自动在点位下方 / 上方 / 左 / 右侧择优排布，避免地名压盖；
5. **沉浸看图** —— 右上角「隐藏界面」或快捷键 **H**，一键收起全部面板只留地图，
   右上角保留「显示界面」小按钮随时找回；
6. **全屏** —— 全屏作用于整个应用容器，标题、控件、图例、南海诸岛附图一并进入全屏，
   不会只剩一张地图；
7. **南海诸岛附图** —— 右下角常驻十段线附图，国家版图完整。

### 性能取舍

卡顿主要来自三处，已逐一处理：

| 问题 | 处理 |
| --- | --- |
| 球面投影渲染开销大（实测约为平面的 2 倍） | 仅开场使用球面，落地即切平面 |
| `mix-blend-mode` 全屏叠层 + `backdrop-filter` 毛玻璃 | 全部移除，改为纯色半透明面板 |
| 瓦片淡入混合、标签逐帧强制回流 | 关闭瓦片淡入；标签改为「先批量读尺寸、再批量写位置」并缓存 |

实测同一视角平移帧耗时：**101.7 ms → 47.6 ms**（约 2.1× 提速）。

## 二、国家版图合规说明

本作品严格遵循《地图管理条例》与国家标准地图：

- 疆域**完整包含台湾省、香港特别行政区、澳门特别行政区**；
- 绘制**南海诸岛与十段线**（`100000_JD` 要素），并在右下角附图中单独呈现；
- 台湾省点击后以省级全幅呈现，并明确提示「台湾省是中国神圣领土不可分割的一部分」；
- 底图为高德地图（依法取得审图号的公开地图服务），无国界错误、无违规标注。

## 三、本地运行

地图数据通过 `fetch` 加载，需以 HTTP 方式访问（不能直接双击 `index.html`）：

```bash
node tools/serve.mjs        # 默认 http://127.0.0.1:8123/
```

或使用任意静态服务器，例如 `python -m http.server 8123`。

### 深链接（可直接定位到某一层级，便于演示与分享）

```
/?go=440000              广东省
/?go=440000,440100       广东省 → 广州市
/?go=440000,440100,440106 广东省 → 广州市 → 天河区
```

## 四、目录结构

```
├── index.html               页面骨架
├── config.js                高德 Key 等站点配置
├── assets/
│   ├── style.css            中国红 / 鎏金 / 墨黑 视觉体系
│   └── app.js               地图与逐级展开的全部逻辑
├── data/
│   ├── geo/                 行政区划边界（省 / 市两级全部本地打包，不依赖第三方接口）
│   │   ├── 100000_full.json 全国（含台湾、港澳、南海诸岛十段线）
│   │   └── <adcode>_full.json
│   ├── gdp.js               GDP 排序数据（省 / 市 / 区县）
│   └── red-sites.js         广东革命文化与红色记忆场馆名录（64 处）
├── vendor/                  MapLibre GL JS v5.6.0
└── tools/
    ├── serve.mjs            本地静态服务器
    ├── fetch-geo.mjs        重新下载省级行政区划边界
    ├── fetch-geo-districts.mjs  重新下载地级市行政区划边界
    └── validate-data.mjs    校验 GDP 数据键名与边界数据是否匹配
```

> 所有行政区划边界均已离线打包（约 26 MB），因此站点**不依赖任何第三方数据接口**，
> 只在加载底图瓦片时联网。首次打开与逐级下钻都很快，且不会因外部服务限流而失效。

## 五、乡镇级（可选，且免费）

**省 → 市 → 区县 三级开箱即用，不需要任何 Key、不需要付费。**

点击区县时，右侧会打开该区县的资料页（所属市、GDP、本层名次、所在市红色场馆名录），
作品内容完整可看。

若希望继续展开到**街道 / 镇 / 乡**并绘制其边界，才需要调用高德行政区划接口：

1. 前往 <https://lbs.amap.com/> 注册开发者（个人开发者有**免费调用额度**，无需付费）；
2. 控制台创建应用，添加 Key，服务平台选择 **Web 服务**；
3. 把 Key 填入 `config.js` 的 `AMAP_KEY`。

填入后，区县点击会自动请求高德行政区查询接口，解析 `polyline` 边界并绘制乡镇图层；
不填则保持现状，不影响任何其他功能。

## 六、数据更新

`data/gdp.js` 中的数值为 **2023 年公开统计口径整理值**，仅用于排序演示。
正式报送前请以《中国统计年鉴》《广东统计年鉴》核准，修改后运行：

```bash
node tools/validate-data.mjs
```

该脚本会校验每个键名是否与行政区划边界数据完全匹配，避免因名称不一致导致排序失效。

## 七、技术栈

- [MapLibre GL JS v5.6.0](https://maplibre.org/) —— 球面投影（globe）、矢量 / 栅格渲染、`feature-state` 动画
- 高德地图瓦片 —— 标准图（`webrd`）与卫星影像（`webst`）
- 阿里云 [DataV.GeoAtlas](https://datav.aliyun.com/portal/school/atlas/area_selector) —— 行政区划边界
- 原生 JavaScript / CSS，无构建步骤
